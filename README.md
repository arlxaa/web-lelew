# hi, ini web porto aku 👋

buatnya pakai Next.js (App Router), TypeScript, sama Tailwind.

## how to run

perlu Node.js 20+ dulu, terus:

```bash
npm install
npm run dev
```

abis itu buka http://localhost:3000. kl mw test versi production: `npm run build` trs `npm start`.
